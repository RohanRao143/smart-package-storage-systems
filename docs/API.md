# API contract

Base path: `/api/v1`. All mutation endpoints require an `Idempotency-Key` header (a UUID generated by the client). Monetary values are integer cents and timestamps are ISO-8601 UTC.

## Lockers

### `GET /lockers?available=true`

Lists lockers and availability. `available=true` returns only unoccupied lockers.

```json
{
  "data": [{ "id": "uuid", "size": "SMALL", "isOccupied": false, "fragileSupport": true }]
}
```

## Store a package

### `POST /packages/store`

```json
{
  "customerId": "uuid",
  "widthCm": 20,
  "heightCm": 15,
  "breadthCm": 10,
  "weightGrams": 1200,
  "hasFragileItems": false
}
```

`201 Created`:

```json
{
  "packageId": "uuid",
  "lockerId": "uuid",
  "lockerSize": "SMALL",
  "pickupCode": "483920",
  "storedAt": "2026-09-05T10:30:00.000Z"
}
```

Errors: `404 CUSTOMER_NOT_FOUND`, `409 LOCKER_UNAVAILABLE`, `422 PACKAGE_EXCEEDS_CAPACITY`.

## Retrieve a package

### `POST /packages/retrieve`

```json
{ "lockerId": "uuid", "pickupCode": "483920" }
```

`200 OK`:

```json
{
  "packageId": "uuid",
  "collectedAt": "2026-09-09T10:30:00.000Z",
  "heldTimeMs": 345600000,
  "chargedAmountCents": 500,
  "walletBalanceCents": 9500,
  "lockerReleased": true
}
```

Errors: `403 INVALID_PICKUP_CODE`, `409 PACKAGE_ALREADY_COLLECTED`, `422 INSUFFICIENT_WALLET_BALANCE`.

## Common error format

```json
{
  "error": { "code": "LOCKER_UNAVAILABLE", "message": "No compatible locker is currently available." }
}
```
